1. Matrix no-op validation

Reads the live 33-byte matrix, writes those exact same bytes with command 0x09, then rereads with 0x08.

This deliberately changes no assignment bytes. A pass requires all 33 bytes to match exactly.

2. Known-good macro memory replay

Replays the exact 51-byte global macro image exported from Lingbao's own IndexedDB: bhop + autoclick. This uses the corrected 00 00 15 12 header.

The validator snapshots the live matrix first. A pass requires all 33 matrix bytes to remain unchanged. If they differ, it attempts immediate restoration and stops.

3. Existing macro binding test

Only enabled after stage 2 passes. Temporarily binds physical Back to existing macro index 0 (bhop) with Lingbao's saved playback mode 3: 70 00 03.

This stage does not modify macro memory again; it only changes the Back button's 3-byte descriptor via command 0x09 and verifies it through 0x08.
